# **App Name**: CalmSense

## Core Features:

- Voice Tone Stress Detection: Analyze voice tone to detect stress levels using AI.
- Facial Expression Stress Detection: Detect stress through facial expressions using MediaPipe/FER+ models.
- Text Emotion Analysis: Analyze text input to determine emotional state using BERT/DistilBERT models.
- Real-time Stress Scoring: Provide a stress score (0-100) based on combined analysis.
- AI-Recommended Relaxation Techniques: Suggest relaxation techniques (breathing, meditation, yoga) using AI recommendations tool.
- Mood Journal: Enable users to log their mood and track stress triggers over time, stored in Firestore.
- Dashboard with Stress Analytics: Display stress analytics and progress charts for user's review.
- Notifications: Setup notifications to promote meditation, and inform the user when stress level are high
- AI Chat Companion: Integrate an AI chat companion to offer real-time support and relaxation tips.
- Admin Web Panel: Provide an admin panel to view anonymized student stress trends stored in Firestore, accessible by the placement cell.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to evoke calmness and sophistication.
- Background color: Dark blue (#303F9F) with 20% saturation, providing a futuristic feel while maintaining readability.
- Accent color: Light blue (#03A9F4), an analogous hue with contrasting brightness and saturation, for highlighting interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral, and user-friendly interface.
- Use minimalist and clear icons that visually represent stress levels, relaxation techniques, and mood tracking. Ensure they are consistent with the futuristic theme.
- Employ a dark, futuristic UI with gradient blue-purple themes. Use blurred glass cards (glassmorphism) to create depth and focus.
- Implement smooth and subtle animations for transitions, loading states, and user interactions to enhance the app's user experience.
